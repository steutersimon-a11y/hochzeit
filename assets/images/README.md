Die Inline-Bilder des Chats standen dem Dateisystem beim Erstellen noch nicht als Originaldateien zur Verfügung. Deshalb zeigt die Einladung bis zum Einfügen eigene florale Grafiken. In `wedding-config.js` die passenden Dateipfade eintragen oder den kostenlosen Editor mit `?edit=1` verwenden. Der Editor kann eine vollständige einzelne HTML-Datei inklusive eingebetteter Bilder speichern.
