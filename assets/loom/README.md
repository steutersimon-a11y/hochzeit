# Durchgehendes Leinen für Marie & Simon

Die aktuelle Gestaltung setzt freigestellte Originalmotive auf eine einzige durchgehende Leinentextur. Die bisherigen vollständigen Leinenbilder bleiben als frühere Versionen im Ordner, sind aber nicht mehr eingebunden. Alle neuen Dateien wurden intern mit der Bilderstellung erzeugt beziehungsweise aus den eigenen Stickmotiven freigestellt. Kirchen- und Restaurantarchitektur stammen aus den eigenen Repository-Bildern.

| Aktuelle Datei | Verwendung |
| --- | --- |
| `linen-ivory.webp` | Gemeinsamer heller, feiner Leinenhintergrund des ganzen Dokuments |
| `opener-blue.webp` | Hochformat mit nachtblauen Perlenvorhängen, rauchblauen Schleifen und eigener Kirche auf hellem gesticktem Pflaster |
| `opener-blue-desktop.webp` | Breite transparente Desktop-Komposition derselben Motive |
| `welcome-blue.webp` | Rauchblaue und mauvefarbene Glyzinien, Perlen und Seitenrosen |
| `stitched-sprig-blue.webp` | Offene Ranke mit Rosen, Perlen und rauchblauen Knötchen |
| `gift-bow-blue.webp` | Rauchblaue Schleife mit Perle für den Geschenkhinweis |
| `medallion.webp` | Bestehendes transparentes Perlenmedaillon für drei Countdown-Werte |
| `timeline-blue.webp` | Sechs freigestellte Ablaufmotive mit blauen Stickdetails im proportionalen 3×2-Bogen |
| `church-edition.webp` | Freigestellte eigene Kirche mit abgerundeter Pflanzung und freien Rändern |
| `mago-flow.webp` | Freigestelltes Mago mit Terrasse |
| `farewell-swans-blue.webp` | Schwäne mit einer rauchblauen Fadenspur zwischen Rosen und Blättern |

Mit Ausnahme der Leinentextur besitzen die Motive transparente Hintergründe. Der mobile Opener hat ein 2:3-Seitenverhältnis. Die beiden kleinen Ornamente haben ein Verhältnis von 3:1. Der Desktop-Opener ist 4:3, die Schwäne 3:2. Die quadratische Icondatei enthält sechs 2:3-Zellen. CSS erhält alle Proportionen. Namen und Angaben bleiben bearbeitbarer HTML-Text.

Die Grafikdateien der Referenzwebsite werden nicht eingebunden. Die Analyse des tatsächlichen Seitenaufbaus ist in `../../DESIGN-REFERENZ.md` dokumentiert. Originale und frühere eigene Gestaltungen bleiben erhalten.
